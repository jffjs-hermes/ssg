# Welcome

Hello and welcome to the ssg example site.

This is the first paragraph. It links to the [index](/index.html) and to a
[tutorial](/guides/tutorial.html) elsewhere on the site.

## What you can do

- Write pages in Markdown
- Link between them
- Drop static assets into the same tree
- Rebuild from source in one command

> Tip: every `.md` file becomes a `.html` page, and everything else is copied
> through untouched.
