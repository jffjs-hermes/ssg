# ssg example site

A minimal static site built with `python -m ssg build example dist`.

This site shows off the Markdown features ssg supports: **headings**,
*emphasis*, `inline code`, [links](/guides/tutorial.html), lists, fenced code
blocks, and block quotes.

## Posts

- [Welcome](/welcome.html)
- [Why a static site generator](/posts/why-ssg.html)
- [Markdown the spec way](/posts/markdown-spec.html)
- [A fenced code delight](/posts/code-samples.html)

To rebuild the site:

```bash
python -m ssg build example dist
```
